# Screenshots

Captured from the live app (https://ikawa-meek-0s-projects.vercel.app) in a 390×844 phone viewport at 2× scale, saved as JPEG. Retake them with `node e2e/capture-readme.mjs` (run from `app/`), then convert the PNGs as shown at the end of that script.

| File | What it shows |
|---|---|
| `start.jpg` | First screen: three guided demo cases (no PIN, separate storage), then the agent PIN |
| `home.jpg` | Home after unlocking: how a case works, farmer ID, farm area, rain date, Start |
| `consent.jpg` | Step 1: three separate consents, each with audio |
| `photos.jpg` | Step 3: worst-row and good-row bags; take a photo or choose several from the phone |
| `question.jpg` | A picture question with audio, answered by voice or tap |
| `result-leaf-rust.jpg` | Result: verdict, strength of evidence and the one action for this week (demo, leaf rust) |
| `cannot-read.jpg` | Mite-damaged leaves: "I cannot read this leaf", then send to a person |
| `leaves-healthy.jpg` | Healthy leaves: points away from leaf disease and offers a no-cost action |
| `send-sms.jpg` | The whole case in one SMS (160 characters or fewer), officer number and reply code |
| `officer.jpg` | Officer page: paste the SMS, read the decoded case, choose a reply card |
| `cooperative.jpg` | Cooperative page: saved cases, storage used, export |
| `kiswahili.jpg` | Kiswahili with the machine-drafted translation notice |
| `rain-history.jpg` | Rain for the farm's area as of a chosen date (satellite estimate) |
